# 004G — Golden path de lanzamiento

Cadena demostrada (tests de producción + wizard nuevo):
producto espejado → recepción DEMO etiquetada (wizard) → visible al público →
descubrimiento por colección/filtros → PDP → cantidad → PB/USD → reserva →
oversell concurrente bloqueado → checkout → pago observado (fixture) → pedido
→ picking → empaque → envío (ledger baja; available 0 ⇒ oculto) → devolución
→ inspección → reintegro o aislamiento por daño → supervisión Internal OS.
