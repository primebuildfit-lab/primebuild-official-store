# 004D — Flujo de diseño del propietario

1. Pides por clave: «Redesign PB_X.SECCION» o «nueva versión de PB_X».
2. Se trabaja en DRAFT (templateVersion+1 si ya existía) — invisible al público.
3. Revisas (IN_REVIEW) → apruebas (APPROVED).
4. Publicación explícita (PUBLISHED); la versión anterior queda SUPERSEDED —
   nunca se sobrescribe una publicada (mismo régimen que las plantillas §17).
5. Todo el copy/los assets viven en slots tipados: un rediseño no puede romper
   la estructura de la página.
