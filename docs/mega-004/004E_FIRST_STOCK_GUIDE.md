# FIRST_OWNED_STOCK_RECEIVING_GUIDE

1. Admin → Inventario → **Wizard de recepción**.
2. Elige el producto espejado (los 52 de Shopify están listos).
3. Confirma variante/SKU (el SKU enlaza ledger↔catálogo; barcode visible).
4. Escribe/escanea el código si difiere — el campo SKU es el vínculo.
5. Almacén (por defecto `alm-principal`) + cantidad CONTADA + condición.
6. Añade la evidencia (albarán/OC/foto). Desmarca DEMO para stock real.
7. Contabiliza → el panel de verificación muestra onHand/available.
8. Comprueba «Visible al público: SÍ» (política default: basta stock OK).
9. Comprueba el precio PB/USD calculado del contrato.
10. Envío rápido: seguirá NO elegible hasta registrar transportista+SLA (decisión operativa).
11. ¿Error? «Revertir con movimiento compensatorio» — auditado, sin borrar nada.
